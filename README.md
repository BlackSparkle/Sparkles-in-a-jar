# Sparkles-in-a-jar
Site for artists (opensource)



Одна из особенностей отличающих Sparklesinajar от других сервисов арт хостинга будет переключение между блогом и галлереей.
При открытии будет открываться галерея плиткой, но также ее можно будет переключить в формат блога с большим вниманием к авторству
